STEP 1: Enable GitHub Pages (one time, 4 clicks)
------------------------------------------------------------
1. Open:  https://github.com/aadhipkd/iitpkd-mws-website/settings/pages
2. Under "Build and deployment", find "Source"
3. Click the dropdown and choose:  GitHub Actions
   (A deploy starts automatically in the Actions tab.)

------------------------------------------------------------

------------------------------------------------------------
STEP 3: Run the first real build
------------------------------------------------------------
1. Open:  https://github.com/aadhipkd/iitpkd-mws-website/actions
2. Click the workflow:  Build and Deploy to GitHub Pages
3. Click the grey  Run workflow  button (right side)
4. Leave branch as  main  -> click green  Run workflow
5. Wait ~2 minutes; the dot turns green when done.
